# AikoDeck

Ton iPhone (ou n'importe quel téléphone) devient un Stream Deck pour ton Mac : de gros boutons pour DaVinci Resolve, la musique, AikoFlow, tes applis… Rien à installer sur le téléphone.

## Utilisation

1. Lance AikoDeck : un QR code s'affiche.
2. Téléphone sur le même Wi-Fi, scanne le code avec l'appareil photo.
3. Dans Safari : Partager → « Sur l'écran d'accueil » pour l'ouvrir comme une appli.

« Modifier les boutons… » sur le Mac : pages, emoji, couleurs et action de chaque bouton (raccourci clavier envoyé à une appli précise, ouvrir une appli ou un lien, taper un texte, lancer un Raccourci, commande Terminal, musique et volume).

## Sécurité

Seuls les appareils qui ont scanné le QR code peuvent piloter le Mac. « Nouveau QR code » déconnecte tous les autres.

## Installation (Mac)

Double-clic sur `macos/Installer AikoDeck.command`, puis autoriser AikoDeck dans Réglages Système → Confidentialité et sécurité → Accessibilité (pour envoyer les raccourcis).
